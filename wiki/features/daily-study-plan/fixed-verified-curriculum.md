# Fixed curriculum with verified links

## Summary

The curriculum is a fixed list in the source code, and every link was checked before it went in.

## Context

The plan shows links to study from each day, on the widget itself. The stated requirement during development was that every link has to be real. From the development session of 2026-10-26.

## Decision

Keep all lessons in `Curriculum.kt` as data. Each DSA problem was confirmed against LeetCode's API, which also supplied its official title and difficulty and confirmed it isn't paid-only. All 132 exist and are free. System design and AI links went through a link checker, and the one dead link found was replaced.

Each lesson has a title, URL, tag, and optionally a summary and a concrete task. These need no network.

## Alternatives considered

None were weighed at the time. A Claude-powered "explain this lesson" button was suggested as a later addition and wasn't built. It would need an API key.

## Consequences

- Links were only verified once, on 2026-10-26, and can rot.
- Changing the plan needs a rebuild and reinstall.
- The content can't adapt to the learner.

## Open questions

- Should the link checker be added to the repo so links can be re-verified? It was a temporary script, and it's gone.
